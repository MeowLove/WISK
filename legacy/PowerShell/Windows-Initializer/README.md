# Windows 11 Initializer

## 概览

这是面向 Windows 11 25H2（内部版本 26200）及更高版本的系统初始化工具。它保留旧脚本中的功能清单，但将安装动作拆分为可选、可预览、可通过配置文件重复执行的项目。

工具不会修改系统执行策略，不会保存账户密码，也不会覆盖旧的 `待整理合并powershell脚本`。

## 启动

工具必须以管理员身份运行。若从普通 PowerShell 启动，它会自动请求 UAC 提升并在提升后的 64 位 Windows PowerShell 中继续执行。此命令只对本次进程临时绕过执行策略，不修改系统或用户的执行策略：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Initialize-Windows.ps1
```

交互菜单按“系统与账户、运行库、常用软件、开发与虚拟化、网络与系统增强、离线维护”分类。进入分类后使用 ↑ / ↓ 移动、Space 勾选或取消、A 全选、N 全不选、Enter 返回主菜单；勾选完成后在主菜单按 `E` 统一执行。环境状态和帮助位于主菜单的 `M`“更多工具”。

对需要参数的项目，`[x]` 表示已勾选但尚未配置，`[*]` 表示已配置。主菜单按 `G` 打开已勾选项目的配置向导；按 `E` 时若存在缺失配置，也会自动进入配置向导。

`G` 进入的是“已选项目配置列表”：主机名、本地账户和显示语言分别独立设置。每完成一项都会立即保存到当前草稿；输入错误只返回配置列表重试，不会清空之前已经填写的内容。主机名会在该项目内循环校验，直到输入合法值或用户返回配置列表。

## 实验性：Device setup region（安装时地区）

“实验性：处理 Device setup region（安装时地区）”位于“系统与账户”列表最底部，是独立的高风险项目。它只写入 `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Control Panel\DeviceRegion` 的 `DeviceRegion` DWORD（Windows GeoID）；不会修改“Country or region”、区域格式、当前用户 Home location 或 UCPD。配置向导提供中国、香港、日本、韩国、新加坡、台湾、英国、美国等预设，也支持输入任意有效 Windows GeoID。

此项目可能被 UCPD 或组织策略拦截，失败不会影响同一队列中的其他初始化项目。工具不会关闭、删除、修改或绕过 UCPD；若 UCPD 或组织策略拒绝或后续重置该值，应记录结果并保留系统现状。配置文件使用 `DeviceSetupRegionGeoId`，例如英国为 `242`、中国为 `45`、美国为 `244`。

## 本地账户

“创建或更新本地账户”是通用账户列表编辑器。可新增、编辑或删除账户，并指定管理员/普通用户、密码永不过期、是否隐藏本机登录界面，以及是否加入远程桌面用户组。隐藏只影响本机登录界面的账户列表，不会禁用账户；RDP 权限只加入账户组，不会自动开启系统远程桌面。新增时若用户名已存在，编辑器会自动以系统当前值作为默认值；通过 `I` 导入的账户首次编辑时也会刷新当前值，之后再次编辑则保留未执行的草稿修改。`R` 可显式重新读取一个账户的系统当前值，并保留草稿中已安全设置的密码。新增和编辑时的密码选择只有“现在安全设置”与“保留已有密码”；新账户必须在编辑器中设置密码，且“密码永不过期”默认选择“是”。`I` 会只读列出当前本地账户，使用空格勾选后导入执行草稿；导入本身不会修改系统，且导入的账户默认保留原密码。`P` 可为列表中全部账户依次设置密码。账户任务不会在最终执行阶段再询问密码。交互菜单的密码只保留在本次 PowerShell 会话内；配置文件则可显式保存密码。账户任务不再包含任何专属账户模板；必须通过账户编辑器或配置文件明确提供 `Accounts`。

## 语言与显示

语言与显示菜单按初始化顺序提供：简体中文（中国）、简体中文（新加坡）区域格式、繁体中文（台湾）、繁体中文（香港）区域格式、英文（美国）、英文（英国）、显示语言范围、字体补充和无线显示器。简体中文（中国）、繁体中文（台湾）、英文（美国）和英文（英国）会通过 `Install-Language` 安装完整 Windows 显示语言包，并补齐当前 Windows 映像实际提供的 Basic、手写、OCR、文本转语音、语音识别及中文字体功能；安装后会登记到当前用户的“首选语言”列表。简体中文（新加坡）和繁体中文（香港）是当前用户的区域格式选项，用于设置日期、数字和货币格式。

简体中文（新加坡）与繁体中文（香港）不是可独立安装的 Windows 显示语言包，因此不会出现在 Windows 设置的“首选语言”卡片中，也不能作为“Windows 显示语言”目标。它们只修改当前用户的区域格式，两个项目互斥，避免同一次运行中发生静默覆盖；不会自动安装简体中文（中国）或繁体中文（台湾）语言包。若需要对应中文显示语言，请显式勾选相应语言包。微软的可用语言包表也将 `zh-HK` 标注为不再使用，并指向 `zh-TW`；`zh-SG` 不在 Windows 桌面完整语言包列表中。

“设置 Windows 显示语言范围”是独立项目。配置时可以选择当前用户显示语言、系统首选 UI 语言，以及是否把当前用户的语言、输入法和区域设置同步到欢迎界面和新账户。默认不会修改区域格式、默认输入法或非 Unicode 系统区域。

“字体补充（日本、韩国、欧洲、印度语）”也是独立的可配置项目。按 `G` 可分别选择日文字体、韩文字体、欧洲补充字体和印度语（天城文）字体；只需兼容日文时只勾选“日文字体”。`A` 会安装该项目提供的全部四类补充字体，但这不是覆盖所有书写系统的“全球字体包”。

查看状态、目录和执行计划：

```powershell
.\Initialize-Windows.ps1 -Action Status
.\Initialize-Windows.ps1 -Action Catalog
.\Initialize-Windows.ps1 -Action Plan -Tasks runtime-dotnet-8,app-vscode
```

使用配置文件执行：

```powershell
.\Initialize-Windows.ps1 -Action Apply -ProfilePath .\config\profile.example.psd1
```

高风险项目（例如 RDP Wrapper、DNS 服务或来源需自行确认的离线安装包）还需要：

```powershell
.\Initialize-Windows.ps1 -Action Apply -Tasks system-rdp-wrapper -AllowRisky
```

## 配置文件

配置文件是 `.psd1` 数据文件。复制 `config\profile.example.psd1`，指定 `Tasks`、可选的 `ComputerName`、`Proxy` 和 `AssetRoot` 即可。账户的 `Password` 存在时会设置或更新密码；省略它时仅保留已存在账户的密码，新账户则会被拒绝执行。密码不会输出到日志。明文方式便于跨机器初始化，但必须将配置文件排除在 Git、云同步、邮件附件和非加密备份之外。

## 离线资产

旧脚本所需的 ZIP/EXE/BAT 等文件没有被复制进本项目。若选择 `offline-*` 或 `legacy-*` 项目，请把你有权使用并已自行验证的文件放在 `assets\` 下，并保留旧脚本中的相对目录名称。执行计划会预先提示缺失资产。

## 风险边界

- 默认集合仅包含基础运行库与常见 WinGet 软件。
- 改主机名、创建账户和启用 Windows 功能属于系统级操作。
- 高风险项目默认禁止执行，必须显式传入 `-AllowRisky`。
- 不包含旧脚本中遗留的授权密钥或凭据。

## 日志

每次执行在 `logs\` 下创建独立日志文件，记录每个项目的成功或失败。失败后可用相同任务 ID 或配置文件重新执行；已安装的 WinGet 软件和已启用的 Windows 功能会自动跳过。
