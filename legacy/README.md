# Legacy 集成目录

这里保存 Windows Initializer 第一代 PowerShell 实现和历史脚本，供 V1 开发期间进行逻辑参考和回归比对。

- `legacy/PowerShell/Windows-Initializer/`：原 Windows Initializer 主程序、模块、配置、worker 和本地运行输出。
- `legacy/PowerShell/PowerShell-Switch/`：PowerShell 终端切换工具。
- `legacy/PowerShell/待整理合并powershell脚本/`：历史初始化脚本集合。

该目录在 V1 发布前保持只读参考状态，不删除、不覆盖、不重命名其中的脚本。
